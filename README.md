# TutorKG 🎓
Веб-приложение для поиска репетиторов в Бишкеке. MVP.

## 🛠 Стек
- **Frontend**: React 18 + Vite + TailwindCSS + Socket.io-client
- **Backend**: Node.js + Express + Prisma + SQLite + Socket.io
- **Видео**: Jitsi Meet (внешний iframe)

## 🚀 Локальный запуск
1. `cd backend && npm install && npx prisma migrate dev && npx prisma db seed`
2. `npm run dev` (запустится на :5000)
3. В другом терминале: `cd frontend && npm install && npm run dev` (:5173)
4. Откройте `http://localhost:5173`

## 🔑 Тестовые аккаунты
- 🎓 Ученик: регистрация через форму
- 👨‍🏫 Репетитор: `anna@example.com` / `password123`
- 👑 Админ: `admin@tutor.kg` / `admin123`

## 📦 Структура
Чистый разграниченный монорепозиторий. Все файлы синхронизированы и готовы к работе.
